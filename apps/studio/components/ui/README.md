# Studio UI primitives

Button, Textarea and Popover are owned copies from the official shadcn/ui `new-york` registry, with its MIT license retained here. Dependencies are pinned in the Studio workspace. `components.json` records the registry configuration.

Tailwind 4 provides utilities. Studio supplies scoped obsidian/accent tokens; portalled popovers receive the same tokens through `studio-popover`. The public site's theme remains separate. Popover accepts a portal container so comparison calibration works inside browser fullscreen.

`app/studio/prompt-composer.tsx` composes these primitives for scene chat, appearance direction and new takes. It adapts Phantasmo's prompt bar: plus/input/action stay inline in a 46px desktop pill until text wraps, then text uses the full width above the action row. Floating composers cap their width at 560px; touch pointers keep larger button targets. The plus opens a vertical attachment/suggestion rail. Scene navigation and motion controls live in the right sidebar tabs. `studio-sidebar.tsx` shares tab semantics, keyboard navigation and collapse controls across Scene, Review and saved takes. Measuring against a stable inline width prevents collapse/expansion oscillation; long text scrolls after 112px. Hidden tab panels defer composer measurement until visible; resize writes run outside ResizeObserver delivery. `canvas-dock.tsx` measures the floating review composer so comparison playback stays clear as prompts grow. Scene and provider state stay in their existing owners; presentation components do not approve or submit provider jobs themselves.
